# 0002 视觉：只有深色，anthracite 令牌，Theme 是唯一来源

- 状态：已采纳
- 日期：2026-10-30
- 依据：`e713859`；本分支 `7f1e7f6`、`ec30c23`、`a865307`

## 背景

面板是一块悬浮在桌面上的玻璃，和 Dock、HUD 同类。此前支持浅色、深色与跟随系统三种外观，各视图里散落
着明暗分支和颜色字面量，维护两套配色的成本高，效果也不统一。

## 决定

- 只有深色：启动时把应用外观固定为 `.darkAqua`，删掉外观选项和全部明暗分支。
- 配色取 Tern 设计系统的 anthracite 主题：冷灰蓝中性色加一个 ember 强调色，按梯子组织。
- `Theme` 是颜色、圆角、阴影、透明度和动效的唯一来源，视图里不写字面量。规则与例外写在
  [DESIGN.md](../DESIGN.md)。

## 放弃的方案

- **跟随系统明暗**：要给每个令牌维护两个值，并在浅色下重新调玻璃的遮挡效果。
- **使用系统语义色**（`labelColor`、`windowBackgroundColor`）：会随系统外观变化，与固定深色冲突。

## 后果

浅色系统下 Trove 仍是深色。新增界面时必须先有令牌；缺的令牌要加进 Theme 并在 DESIGN.md 写明用途。

## 什么时候重新考虑

有足够多的用户明确需要浅色时。届时 Theme 的令牌改为按外观取值，视图代码不用改。
