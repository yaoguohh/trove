# 0009 设置放在状态菜单里，状态菜单是无边框面板

- 状态：已采纳
- 日期：2026-06-14、2026-06-15；2026-11-13（设置收进 AppSettings）
- 依据：`71ff82e`、`febc6f8`；本分支 `e005c3b`

## 背景

设置只有几项（快捷键、链接预览、后台运行），单独的设置窗口显得笨重。`NSPopover` 一定会画出箭头，
而且背景会透出来。

## 决定

- 不设独立的设置窗口，所有设置以开关和录制器的形式放在状态菜单里。
- 右键点菜单栏图标弹出状态菜单（左键开关面板），它是一个手动定位在图标正下方的无边框面板
  （`KeyablePanel`），背景用与面板相同的玻璃；点到外面、按 Esc、再点一次图标或应用失焦时关闭。
- 设置的键、默认值和当前值只在 `AppSettings` 一处；状态菜单直接绑定它。
- 权限缺失（辅助功能、剪贴板访问）和快捷键冲突在状态菜单里提示。

## 放弃的方案

- **独立的设置窗口**：项目少，打开窗口的成本高于收益。
- **`NSPopover`**：带箭头，背景透出。
- **标准 `NSMenu`**：放不下快捷键录制器这类控件。

## 什么时候重新考虑

设置项多到状态菜单一屏放不下时。
