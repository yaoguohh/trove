# 0008 默认只在菜单栏运行

- 状态：已采纳
- 日期：2026-06-03；2026-09-02（避免启动时闪现 Dock 图标）
- 依据：`6e91e9b`、`1c7d20c`

## 背景

剪贴板管理器常驻后台，Dock 图标没有用处（Maccy、Ice 也是如此）。只在启动后切换激活策略时，Dock 图标会
先出现再消失。

## 决定

- `Info.plist` 声明 `LSUIElement`，启动时就以 accessory 身份运行。
- 状态菜单的「后台运行」开关可以切换到常规应用（显示 Dock 图标），选择保存在 `AppSettings`。

## 后果

Trove 没有主菜单，系统的编辑菜单快捷键（⌘C、⌘V、⌘A、⌘W）需要自己接到窗口上（`EditingShortcuts`、
`InspectorWindow`）。

## 什么时候重新考虑

需要完整主菜单（例如独立的设置窗口）时。
