# 0011 预览分两种：一次性的 Peek 和独立的 Inspector；单个链接交给浏览器

- 状态：已采纳
- 日期：2026-06-04 至 2026-06-11
- 依据：`17c92a8`、`67b6e14`、`ef8a4d5`、`d1d206d`

## 背景

卡片只能显示几行。用户需要两种查看方式：在面板里快速瞄一眼，以及打开大窗口细看、选中文字、并排比较。

## 决定

- **Peek**：按空格在面板上方弹出一个带尾巴的气泡，显示选中卡片的大图或文字前 4000 字符。它在自己的不激活
  面板里，不抢走面板的键盘焦点；选中一变就关闭，不跟随。点击气泡任意位置打开 Inspector。
- **Inspector**：右键「预览」或点击 Peek 打开的独立窗口，可同时打开多个、可置顶、可在调度中心里看到。文字用
  只读 `NSTextView` 显示，可以原生选中和 ⌘C；JSON 美化显示（可切换原文）；最多排版 256 KB。
- 单个裸 URL 不在应用内渲染网页，直接用默认浏览器打开。
- 富预览（JSON 美化等）只在 Inspector 里做，卡片上不做，保证面板滚动流畅。

## 放弃的方案

- **Peek 跟随选中切换**：快速移动选中时气泡不停变化，令人眼花。
- **在应用内渲染网页**：只是重复浏览器的功能。

## 什么时候重新考虑

需要在卡片上直接预览更多类型（如 Markdown 渲染）时，先评估对滚动性能的影响。
