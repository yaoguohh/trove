# 0006 捕获：轮询 changeCount，文本优先，敏感内容在读取前跳过

- 状态：已采纳
- 日期：2026-10-30；2026-11-13（读取前跳过、changeCount 回声抑制）
- 依据：`0189ec2`；本分支 `07a93b8`、`bf9e64d`

## 背景

`NSPasteboard` 没有变化通知，所有剪贴板管理器都靠轮询。一次复制往往同时带有文本和图片（Pages、Numbers、
预览复制选区时会附带 PDF/TIFF 渲染），密码管理器和文本扩展工具也会写剪贴板。

## 决定

- 每 0.5 秒（容差 30%）比较一次 `changeCount`，变了才读类型和内容；定时器加在 `.common` 模式，菜单和
  拖拽期间也继续。
- 先看类型：带 concealed 标记（1Password、KeeWeb 等）或 transient 标记（Keyboard Maestro、Typinator 等）
  的变化直接跳过，此时还没有读取内容。
- 再决定收什么：有文本就收文本；只有文本只是图片的地址（如 Safari 复制图片时附带的 URL）时才收图片。
- 单张图片上限 64 MB。
- Trove 自己写回剪贴板后，让监听方把当前 `changeCount` 视为已处理，不会把自己的写入当成新复制。

## 放弃的方案

- **图片优先**：富文本复制时会存进一张选区截图，而不是用户真正要的文字。
- **按内容比对识别自己的写入**：要在内存里留一份完整文本或 PNG，大内容时浪费内存。

## 后果

复制后最多约 0.65 秒才出现在历史里。

## 什么时候重新考虑

macOS 提供剪贴板变化通知时改用通知。
