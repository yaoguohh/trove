# 0014 权限引导：欢迎窗口加 PermissionFlow 拖拽浮窗，不再弹系统授权框

- 状态：已采纳
- 日期：2026-11-21
- 依据：参考 Snug 的权限引导（同样基于 PermissionFlow）

## 背景

Trove 要两项权限：辅助功能（发送 ⌘V 粘贴）和"从其他App粘贴"（macOS 15.4 起读取剪贴板）。原来的做法：

- 第一次粘贴时调用 `AXIsProcessTrustedWithOptions` 弹出系统授权框，这次粘贴只复制；
- 菜单栏菜单里各有一行提示，点了只打开系统设置，用户要自己在列表里找到 Trove；
- 首次安装没有任何说明，Trove 只在菜单栏出现一个图标。

另外 macOS 27 把"辅助功能"改名为"设备控制和数据访问"，文案里写死的旧名字会让人找不到。

## 决定

- 依赖 [PermissionFlow](https://github.com/jaywcjlove/PermissionFlow)（MIT）。授权辅助功能时，由它打开
  系统设置的对应页面，在旁边停靠一个带 Trove 图标的小浮窗，用户把图标拖进列表即可。浮窗的语言跟随
  Trove 自己的界面语言。它的资源包由 `scripts/package-app.sh` 放进 `Contents/Resources`。
- 新增欢迎窗口（`WelcomeController`）：应用图标、三行用法、两项权限的实时状态和各自的操作按钮。
  - 只在全新安装时自动出现（没看过欢迎窗口，且历史为空）；从旧版本升级的用户不会被打扰。
  - 粘贴时发现缺辅助功能权限，每次启动最多弹出一次，说明这条已经复制好、按 ⌘V 即可，并提供授权按钮。
- 菜单栏菜单里的辅助功能提示行改为直接打开拖拽引导。剪贴板一行打开系统设置，并在第二行写明要做什么。
- 不再调用系统授权框（`AXIsProcessTrustedWithOptions` 的 prompt 选项）。
- 权限名称跟随系统版本：辅助功能的名称取自 PermissionFlow；剪贴板那一页用系统设置里的原文
  "从其他App粘贴"。
- 引导期间每秒检查一次是否已授权（系统没有对应的通知），授权后自动收起浮窗、把欢迎窗口带回前台；
  15 分钟没授权就停止检查。

## 放弃的方案

- **自己实现精简版浮窗**：外观能统一成 Trove 的深色令牌，但要自己维护设置窗口跟随、拖拽和多语言。
  浮窗停靠在系统设置旁边，用系统风格反而更协调。
- **像 Snug 一样把 PermissionFlow 复制进仓库**：Snug 复制是因为只有命令行工具时 `@State` 宏编译不过；
  本项目用完整 Xcode 构建，直接依赖上游更省事，升级也方便。
- **继续用系统授权框**：系统授权框只说"要控制这台电脑"，不说为什么，也不带用户找到开关。

## 后果

- 外部依赖从一个（Sparkle）变为两个。
- 浮窗是 DESIGN.md 例外清单里新增的一项：它不用 Theme 令牌。
- "从其他App粘贴"在 macOS 15.4–26 上的叫法和控件样式未经核实；文案写成"允许 Trove"，不指明是开关
  还是选项。

## 什么时候重新考虑

PermissionFlow 停止维护或不再适配新系统时；或 macOS 提供了可以直接查询、订阅授权变化的接口时。
