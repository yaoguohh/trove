# 0010 删除可撤销，清空历史需要确认

- 状态：已采纳
- 日期：2026-06-08；2026-11-13（清空确认）
- 依据：`f1afbc2`；本分支 `e005c3b`

## 背景

在面板里按 ⌦ 删除卡片很容易误按。删除如果立刻删掉图片和 sidecar 文件，就无法恢复。

## 决定

- 删除的 Clip 进入一个只在内存里的撤销栈（会话内，最多 25 条），⌘Z 恢复最近一次删除。⌘Z 只在搜索框为空
  时生效，否则交给搜索框的文字撤销。
- 删除时不删文件，直到它被挤出撤销栈；恢复时字节级一致。
- 恢复时：所属收藏板已删除就放回未分组；内容已被重新复制过就不重复创建；当前筛选看不到它时回到全部历史。
- 启动时清理没有任何 Clip 引用的文件，兜住意外退出。
- 「清空历史」一次删掉所有未置顶的 Clip 和它们的文件、不能撤销，所以两个入口（状态菜单、面板菜单）都先
  弹确认框，默认按钮是取消。

## 放弃的方案

- **撤销栈落盘**：重启后还能撤销的需求很少，代价是删除的内容在磁盘上停留更久。
- **清空历史也纳入撤销**：要保留全部文件直到撤销过期，磁盘占用可能翻倍。

## 什么时候重新考虑

用户需要跨重启恢复误删的内容时。
